# Klášterka

Malá point & click adventura ve stylu Samorostu nad časosběrem z webkamery na Klášterce (Zadní Planina, Krkonoše).
Ovce chtějí lyžovat — pomoz jim, ať napadne sníh a rozjede se vlek.

Hrát: https://dankaliba.github.io/klasterka/

Běží v prohlížeči bez instalace (HTML + JavaScript + Canvas). Klávesa F = celá obrazovka.
Postavy jsou zatím zástupné, vlastní kresby a zvuky přibudou. Stav vývoje je v [progress.md](progress.md).

Červené K v názvu je němá značka Krkonoš (Klínovky) z Wikimedia Commons, soubor NZ_Klinovky.svg (volné dílo).
